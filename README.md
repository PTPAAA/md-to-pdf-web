# Markdown to PDF 在线转换器

一款基于前端纯浏览器端实现的 Markdown 转 PDF 转换工具，支持实时预览与无损导出。

## 项目概述
在日常开发与文档编写中，Markdown 作为轻量级标记语言被广泛应用。但在汇报、归档、交付等正式场景下，通常需要将 Markdown 文档导出为格式规范的 PDF 格式。
传统的服务端转 PDF 方案存在以下问题：
1. **网络依赖与延迟**：必须将文档内容上传至后端服务器进行编译渲染，受网络带宽限制。
2. **数据隐私风险**：技术文档往往包含公司内部架构、敏感数据或未公开专利信息，上传第三方公有服务器存在泄露隐患。
3. **环境复杂**：后端通常依赖 Chromium / Puppeteer 或 wkhtmltopdf，部署维护成本高。

本项目基于浏览器前端现代技术栈，实现 **“零上传、纯前端、秒级渲染、标准 A4 排版”** 的 Markdown 到 PDF 转换引擎。

## 核心特性
- **纯前端解析与排版**：采用高性能的 Marked.js 引擎，支持标准 Markdown 语法、GFM（GitHub Flavored Markdown）表格、代码高亮等。
- **高保真 PDF 导出**：深度集成 html2pdf.js，配合精确的 CSS 分页与 A4 纸张排版规则（避免标题断裂、图片裁切等排版异常）。
- **极速响应与双栏对比**：左侧编辑区支持 Markdown 原生输入，右侧实时同步渲染预览，所见即所得。
- **隐私保护与零网络开销**：所有解析、渲染及 Canvas 导出流程全部在本地浏览器内存闭环执行，不发起任何外网数据传输，确保文档信息安全。

## 技术架构
```
[ 用户 Markdown 输入 ] 
        │
        ▼ (Marked 解析器)
[ 标准语义化 HTML AST / DOM ]
        │
        ▼ (CSS Paged Media 排版适配)
[ A4 页面排版容器 (Page Breaks) ]
        │
        ▼ (html2canvas 栅格化 / jsPDF)
[ 标准 PDF 文档下载 (work.pdf) ]
```

## 快速使用
1. 直接在浏览器中双击打开 `index.html`。
2. 在左侧文本框内输入或粘贴 Markdown 格式内容。
3. 右侧即时呈现排版样式。
4. 点击顶部的 **“导出为 PDF”** 按钮，即可自动生成并下载标准 PDF 文件。
